## eBAT replication package
The provided replication package contains the source code both eBAT and baseline approach webExplor, along with the instructions to run them. This package also contains the script required to generate the results. 
### Environment Setup
Six open source benchmarked frontend applications are used to evaluate the two approaches. The projects are dockerized and instructions to run them are provided under each project within "test_systems" directory. The provided virtual machine (requires minimum 4GB RAM) contains all the dependencies and configurations required to run the approaches and test systems.
The login credentials are:
user: ```eBAT```
password: ```ebat```

The required dependencies in case of manual environment setup:

 1. Python 3.9.12 (https://www.python.org/downloads/release/python-3912/). Make sure to use the corresponding `pip` version, which is already available with the python installation package via `python3.9 -m pip`.
 2. Docker CE ([https://docs.docker.com/install/](https://docs.docker.com/install/)). Running  `sudo usermod -aG docker ${USER}`  would allow 	`docker` command to run with `sudo`).
 3. Docker Compose (https://docs.docker.com/compose/install/)
 4. The libraries required to run the approaches are defined in `requirements.txt` and can be installed via `pip install -r requirements.txt`

### Instructions to Run
The two projects are located in separate folders and follows the same directory structure and method of execution. As an example, the following instruction are focused on running eBAT.
 1. Run the target application located inside the "test_systems" directory in each project and wait for the docker container to start serving the application.
 2. From the project root directory run `python main.py --project=[dimeshift|pagekit|splittypie|trello|retroboard|petclinic]  [--time=30]`
 3. The approach will run for 30 minutes by default (execution time(in minutes) can be changed using the `--time` parameter). The execution log will be stored in "./res/logs/[approach_name]".
 4. The final results are generated by running the script `generate_results.py` in the "output" directory located at the package root. For convenience and crosschecking, the logs from 15 trials are stored in the same directory. This script generates the detection rate graphs (stored in "./plots"), results of statistical tests and average of the unique failures detected for each project.
