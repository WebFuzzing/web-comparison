## TOM Generator

## Necessary Technologies

* JAVA 8
* Maven

## How to run the project

To run the generator it is necessary to:

* Complete the "DefaultValues" class with the desired values

* Install the package into the local repository: 'mvn clean install'

* Execute TOM Generator: 'mvn exec:java'
